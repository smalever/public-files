# Python для общих скриптов персонального бота

- Интерпретатор: `/opt/data/home/.venv/bin/python`; отдельный пользовательский venv, не окружение core Hermes.
- Базовые зависимости: PyYAML, matplotlib, numpy, Pillow, PyMuPDF; `bot-help` дополнительно требует packaging.
- Создание venv и установка зависимостей — задача администратора по согласованию. Навык не запускает pip/apt автоматически.
- Core Hermes в официальном контейнере находится в `/opt/hermes`; его зависимости и файлы не редактируются пользовательскими скриптами.
- Данные владельца находятся в `/opt/data/personal`, заметки в `/notes`; эти каталоги не являются тестовыми fixtures.
- Для штатного CLI использовать явный интерпретатор. Cron также должен иметь явный interpreter; shebang и автоматическое переключение окружения не заменяют настройку cron.
- Перед диагностикой читать исходник. Проверять Python syntax через `ast.parse` текста без импорта; импорт может выполнять код. Тестировать только на изолированных синтетических данных без production mounts, credentials и сети.
- Не переносить готовый venv между владельцами. Конкретную версию Python и установленные зависимости проверяет администратор в целевом deployment; эта справка не подтверждает их наличие.
