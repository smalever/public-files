# Каталог навыков

Источник — `catalog.yaml`; JSON и эта страница генерируются административным release_catalog.py.

## Личные финансы (`finance`)

Версия: **3.1.0** · Создан: 2026-07-26 · Обновлён: 2026-10-20

Учёт расходов и доходов по счетам, несколько валют, категории, отчёты, заправки и расход топлива на 100 км, импорт выписок Сбера и Озон Банка.

Изменения: Поддержка машинного режима --summary (has_records, count), нормализация дробных сумм float с точкой/запятой, защита от неоднозначности разделителей тысяч (1.200 vs 1,200), ссылка на vendor-normalization.md, безопасное открытие БД через SQLite URI mode=ro/rw, перехват sqlite3.DatabaseError.

## Здоровье (`health-tracker`)

Версия: **3.1.0** · Создан: 2026-07-26 · Обновлён: 2026-10-20

Дневник давления, пульса, сахара, веса; схема лекарств из Obsidian и отметка приёма каждого препарата; справочник препаратов с исправлением опечаток; графики.

Изменения: Поддержка машинного режима --summary, атомарная схема многослотовых препаратов (раздельные дозировки и условия еды), отслеживание приёма по названным препаратам с уточнением слота, расчёт лекарств в дорогу хронологической раскладкой, расчёт элементарного вещества по соли, добавление нативного CLI medical_extract.py на Gemini, атомарный импорт документов с журналом и fsync.

## Импорт анализов (`medical-import`)

Версия: **4.1.0** · Создан: 2026-09-20 · Обновлён: 2026-10-20

Анализы и заключения врачей из PDF и фото: распознавание, черновик, двойное подтверждение, запись в базу без дублей.

Изменения: Переход на нативный CLI medical_extract.py (прямой разбор PDF моделью Gemini без предварительного OCR/раскладки на PNG), обновлённый регламент проверки дублей и явного подтверждения черновиков. Обезличено сетевое правило (только loopback/TLS) и имя бэкапа.

## Питание (`nutrition`)

Версия: **3.1.0** · Создан: 2026-07-26 · Обновлён: 2026-10-20

Дневник питания с КБЖУ по собственному справочнику продуктов и алиасов; напоминание о лекарствах «во время/после еды» при записи приёма пищи.

Изменения: Поддержка десятичной запятой в названиях (молоко 2,5%) и граммовках (12,5г), блокировка сохранения частичного приёма пищи при наличии нераспознанных или неоднозначных позиций (fail-fast), обязательная верификация записи новым соединением mode=ro, машинный режим --summary.

## Рецепты (`recipe-assistant`)

Версия: **0.4.1** · Создан: 2026-09-23 · Обновлён: 2026-10-20

Одно блюдо из того, что есть дома: под остаток КБЖУ на сегодня или без ограничений, если цели не заданы.

Изменения: Учёт условий еды из схемы владельца без универсальных медицинских порогов; уточнены ограничения КБЖУ и способы приготовления.

## Брифы здоровья (`health-reminder`)

Версия: **3.1.0** · Создан: 2026-07-26 · Обновлён: 2026-10-20

Утренний бриф, брифы «до еды», итоги дня по лекарствам и воскресный обзор с графиком; молчат, когда напоминать нечего.

Изменения: Удаление self-reexec блоков из cron-скриптов в пользу явного интерпретатора venv в cron-конфигурации, уточнение поведения вечерней отметки «принял всё» (не закрывает пропущенное утро), указания по проверке синтаксиса через ast.parse в памяти.

## Идеи (`ideas-inbox`)

Версия: **2.1.1** · Создан: 2026-07-26 · Обновлён: 2026-10-20

Быстрая запись идеи в Obsidian по шаблону с добавлением в индекс.

Изменения: Создание новых логических заголовков в индексе Идеи.md при отсутствии подходящего, автоматическое извлечение заголовка и краткого описания по входящим ссылкам (статьи, книги, инструменты, репозитории) через веб-инструменты.

## Заметки (`notes-vault`)

Версия: **2.1.0** · Создан: 2026-09-27 · Обновлён: 2026-10-20

Правила vault владельца: структура, frontmatter, индексы, наведение порядка в заметках.

Изменения: Обновление updated у индекса раздела при добавлении заметок, стандарт структуры исследовательских заметок (TL;DR в первом пункте, технический анализ, таблица вариантов, навигационная строка внизу), регламент изоляции секретов (только в специальную private-заметку).

## Поиск через MCP (`web-search-fallbacks`)

Версия: **2.2.0** · Создан: 2026-08-24 · Обновлён: 2026-10-20

Поиск и чтение через настроенный MCP SearXNG с бюджетами и паузами, без скрытых обходов.

Изменения: Принципиальное изменение концепции навыка (v1.1.1 -> v2.2.0): вместо эскалации curl/browser UA fallbacks при блокировках зафиксирована политика использования исключительно приватного MCP-сервера SearXNG (searxng_web_search и web_url_read) с жесткими квотами символов, паузами вежливости (6 сек) и строгим запретом внешних обходов/сторонних API.

## Справка и обновления (`bot-help`)

Версия: **1.1.0** · Создан: 2026-10-01 · Обновлён: 2026-10-20

Справка, каталог и новости; локальные изменения блокируют обновление. Установка отдельно согласуется с владельцем.

Изменения: Неизменяемый SHA, фиксированный allowlist, ограниченная загрузка без redirects, новости по ID и fingerprint, проверяемый journal rollback. Установка только в административное окно, без force и автоматического слияния.
