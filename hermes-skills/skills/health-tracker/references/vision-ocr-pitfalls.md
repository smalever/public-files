# Vision OCR: типичные ошибки на медицинских документах

## Частые ошибки распознавания

### Медицинские термины

| Vision распознаёт | Правильно | Контекст |
|---|---|---|
| Гемоглобин | **Гликозилированный гемоглобин (HbA1c)** | Если значение ~6-10% и рядом есть глюкоза |
| Моноциты | **Мочевая кислота** | Если единицы мкмоль/л и значение ~200-400 |
| Бикурутин | **Билирубин** | Опечатка OCR |
| Гликоза | **Глюкоза** | Синоним, но в БД используй 'Глюкоза' |
| Липопротеиды | **ЛПВП** или **ЛПНП** | Смотри на реф. диапазон и контекст |

### Единицы измерения

| Параметр | Vision даёт | Правильно |
|---|---|---|
| Гликозилированный Hb | ммоль/л | **%** (проценты) |
| Мочевая кислота | ммоль/л | **мкмоль/л** |

### Правило проверки

**Всегда сверяй единицы измерения с референсным диапазоном:**
- Если референс 4.0–6.0, а значение 9.4 → скорее всего %, не ммоль/л
- Если референс 200–400, а значение 273 → скорее всего мкмоль/л, не ммоль/л
- Если видишь «Гемоглобин» с референсом 4–6 и значением ~9 → это HbA1c

## Рукописные пометки

Vision часто ошибается при распознавании рукописного текста. Паттерн из сессии 12.05.2026:
- Vision увидел «2.70» в нескольких местах → на самом деле это были **целевые значения врача** для разных параметров
- Реальные целевые значения были: < 7%, < 7, < 4.5, < 1.7, < 2.6

**Правило:** Если пользователь говорит про рукописные пометки — НЕ полагайся на Vision. Нарежь документ на фрагменты (dpi=300) и отправь пользователю для визуальной сверки.

## Паттерн «целевые значения врача»

Врач может писать от руки:
- Рядом с повышенным показателем — целевое значение (например, «< 7» рядом с глюкозой 9.81)
- Выделять повышенные показатели подчёркиванием или стрелками

**Приоритет источников:**
1. Пользователь диктует точные цифры → записываем как есть
2. Vision распознал → проверяем по таблице выше
3. Vision не уверен → нарезаем и показываем пользователю
