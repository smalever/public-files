# Справочник категорий финансов

Единый справочник для всех счетов. Скрипты импорта мапят категории из банковских выписок на этот справочник.

**Источник правды:** `finance/scripts/category_map.py`.
Если описание и код расходятся — верить коду.

## Категории

- `groceries` — **Продукты**
  - Продукты, супермаркеты
  - Тип: расход

- `health` — **Здоровье**
  - Аптеки, медицина, здоровье
  - Тип: расход

- `transport` — **Транспорт**
  - Метро, такси, проезд
  - Тип: расход

- `restaurants` — **Рестораны**
  - Кафе, рестораны, еда вне дома
  - Тип: расход

- `clothing` — **Одежда**
  - Одежда, обувь, аксессуары
  - Тип: расход

- `travel` — **Путешествия**
  - Билеты, отели, поездки
  - Тип: расход

- `entertainment` — **Развлечения**
  - Отдых, хобби, развлечения
  - Тип: расход

- `home` — **Дом/ЖКХ**
  - Коммуналка, связь, интернет, ЖКХ
  - Тип: расход

- `household` — **Товары для дома**
  - Бытовая химия, посуда, текстиль, мелочи для дома (полотенца, порошки, губки)
  - Тип: расход

- `it_services` — **IT-сервисы**
  - Серверы, VPS, хостинг, домены, VPN
  - Тип: расход

- `subscriptions` — **Подписки**
  - Яндекс Плюс, Озон Премиум, стриминг, сервисы по подписке
  - Тип: расход

- `electronics` — **Техника**
  - Телефоны, гаджеты, компьютеры, аксессуары
  - Тип: расход

- `gifts` — **Подарки**
  - Подарки близким, поздравления, цветы к праздникам
  - Тип: расход

- `auto` — **Автомобиль**
  - Ремонт, запчасти, ТО
  - Тип: расход

- `fuel` — **Топливо**
  - Бензин, солярка, газ
  - Тип: расход

- `smoking` — **Сигареты**
  - Сигареты, табак
  - Тип: расход

- `legal` — **Юридические расходы**
  - Услуги юристов, адвокатов и нотариусов, юридические консультации и оформление документов
  - Тип: расход

- `other_expense` — **Прочие расходы**
  - Всё прочее, что не попало в отдельные категории
  - Тип: расход

- `marketplace` — **Маркетплейсы**
  - Ozon, Wildberries и т.п.
  - Тип: расход

## Маппинг Сбер

Сопоставление идёт по началу строки (`startswith`).

- `Супермаркеты` → `groceries`
- `Здоровье и красота` → `health`
- `Транспорт` → `transport`
- `Коммунальные платежи` → `home`
- `Автомобиль` → `auto`
- `Рестораны и кафе` → `restaurants`
- `Путешествия` → `travel`
- `Одежда и аксессуары` → `clothing`
- `Отдых и развлечения` → `entertainment`
- `Прочие расходы` → `other_expense`
- `Прочие операции` → `other_expense`

### Знак суммы в Сбере

- `+` перед суммой → доход
- без знака → расход

## Маппинг Озон

Сопоставление идёт по regex-паттернам в порядке сверху вниз.
Полный список — в `category_map.py` → `OZON_CATEGORY_MAP`.

Ключевые примеры:

- `PYATEROCHKA`, `MAGNIT`, `FIXPRICE`, `VKUSNOITOCHKA` → `groceries`
- `NOTARIUS` → `legal`
- `^\d{6,9}$` → `other_expense`
- личные магазины владельца — `ozon_category_patterns` в `finance-settings.yaml` (`references/settings.md`)

### Знак суммы в Озоне

- `+` перед суммой → доход
- `-` перед суммой → расход
