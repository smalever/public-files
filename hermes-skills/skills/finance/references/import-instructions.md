# Импорт банковских выписок

Запускается по ручному требованию. Импортирует выписки из Сбера и Озон Банка в таблицу `transactions`.

## Главное правило

- **Импортёры загружают только расходы.**
- **Доходы, переводы между своими счетами и прочие движения средств пропускаются.**
- Каждый импортёр **полностью перезаписывает свои записи по счёту**, но только если после парсинга есть строки для импорта.
- Если парсер вернул `0` строк, замена **не выполняется**, чтобы не стереть существующие данные по счёту.

## Команды

```bash
/opt/data/home/.venv/bin/python /opt/data/skills-custom/finance/finance/scripts/import_sber.py --run
/opt/data/home/.venv/bin/python /opt/data/skills-custom/finance/finance/scripts/import_ozon.py --run
```

Без аргументов или с `--help` импортёры только показывают справку.

## Структура файлов

```text
/opt/data/personal/finance/          # данные
├── finance.db
├── finance-settings.yaml            # счета и файлы выписок (import.sber / import.ozon)
└── <файлы выписок из настроек>.txt
/opt/data/skills-custom/finance/finance/scripts/
├── finance.py, category_map.py
└── import_sber.py, import_ozon.py
```

## Форматы файлов

- **Сбер**
  - одна строка на транзакцию
  - сумма вида `1 234,56`
  - знак: `+` или без знака
  - дата: `ДД.ММ.ГГГГ ЧЧ:ММ`

- **Озон**
  - многострочные блоки
  - сумма вида `1 234.56`
  - знак: `+` или `-`
  - дата может наследоваться из предыдущей строки

## Формула знака

- **Сбер**
  - `+` = доход
  - без знака = расход

- **Озон**
  - `+` = доход
  - `-` = расход

## Что сохраняется в БД

- `category` — категория из единого справочника
- `vendor` — нормализованное название магазина/места, если его удалось выделить
- `note` — сырой или почти сырой текст операции для контекста

## Добавление новых паттернов

Все маппинги категорий и нормализация vendor лежат в одном месте:
`finance/scripts/category_map.py`.

- **Сбер**
  - категории: `SBER_CATEGORY_MAP`
  - vendor: `normalize_vendor()`

- **Озон**
  - категории: `OZON_CATEGORY_MAP`
  - vendor: `normalize_vendor()`

## Pitfalls

- Кодировка файлов: `utf-8-sig`
- Неразрывные пробелы заменяются на обычные
- Дубликаты по времени и сумме получают суффикс `_N`
- Исполняемая логика теперь обёрнута в `main()`, поэтому модули можно безопасно импортировать в тестах
- Фильтры переводов консервативные: если банк поменяет формулировки, их нужно обновить в коде
