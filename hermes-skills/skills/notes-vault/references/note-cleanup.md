# Наведение порядка в личной заметке

Когда владелец просит «причесать / навести порядок / почистить» заметку.

## Цели
- Сохранить всю значимую информацию: команды, пути, ссылки, шаги восстановления.
- Улучшить читаемость; убрать только шум, дубли и мусорное форматирование.
- Секреты и параметры подключения не удалять без явной просьбы; если просят редактировать — сначала согласовать объём.

## Приёмы
- Смешанный сырой текст → короткие разделы с заголовками.
- Команды — в fenced code blocks.
- Свалку команд раскладывать по разделам: *где лежат файлы*, *конфигурация*, *полезные команды*, *бэкап / восстановление*, *ссылки*.
- Неудачный заголовок можно нормализовать, сохранив узнаваемость.
- Проверить/добавить frontmatter по соглашениям `notes-vault`.

## Pitfalls
- Пересжатие с потерей нюансов.
- Удаление деталей только потому, что они выглядят «шумно».
- Переписывание заметки в новую идею вместо уборки существующей.

## Проверка
Перечитать заметку после записи: нет обрезаний, форматирование цело, ссылки из индекса работают.
