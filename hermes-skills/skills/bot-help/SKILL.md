# Справка бота, что нового и обновление навыков

## Когда использовать

- «что ты умеешь», «помощь», «с чего начать», «расскажи о себе», `/help` в свободной форме;
- «чему новому тебя научили», «что нового», «есть обновления навыков»;
- «обнови навык X», «поставь новый навык», «что изменилось в навыке X».

## Справка «что я умею»

Источник — заметка `/notes/Справка — что я умею.md` (владельцу видна в Obsidian). Нет в корне vault — найти `search_files` по имени `*Справка*что я умею*` или `*справка владельцу*`. Не пересказывай по памяти:

1. Прочитай справку.
2. Ответь коротко: 5–8 ролей одной строкой каждая + 3–4 примера фраз под интересы владельца (если они известны из памяти) + предложение «спроси подробнее про любую тему». Всю справку целиком не вываливай.
3. На «подробнее про X» — раздел справки X своими словами с примерами.
4. Если владелец ещё не настроил базовое (счета, цели КБЖУ, схема препаратов, брифы) — один раз предложи раздел «С чего начать».

Справка устарела (появился/удалён навык, изменилась команда) — предложи правку, покажи её и запиши после согласия; `updated` во frontmatter — текущее время.

## Что нового и обновления

Навыки этого бота публикуются в открытом каталоге (репозиторий `smalever/public-files`, папка `hermes-skills/`, `catalog.yaml`: имя, описание, версия, даты создания и обновления, что изменилось). Встроенные навыки Hermes обновляются с самим Hermes и здесь не участвуют.

```bash
PY=/opt/data/home/.venv/bin/python
SU=/opt/data/skills-custom/notes/bot-help/scripts/skills_update.py
$PY $SU check            # что нового с прошлой проверки, обновления, изменённые владельцем
$PY $SU check --mark     # то же + запомнить дату проверки (после того как рассказал владельцу)
$PY $SU diff NAME        # что поменяется в навыке
$PY $SU install NAME     # план установки (ничего не пишет)
$PY $SU status           # что установлено из каталога
```

Ответ на «что нового»:

1. `check`. Ошибка сети — честно сказать, что каталог сейчас недоступен.
2. `new_since_last_check` — «С <last_checked> появились: …» (title + summary простыми словами); `updates` — «Обновились: …» (`changes`); `not_installed` — упомянуть, если владелец спрашивает про доступные навыки. Пусто — «нового нет, последняя проверка <дата>».
3. После ответа — `check --mark`.

## Установка и обновление (только с явного «да»)

1. `diff NAME` → кратко человеческим языком: что добавится/поменяется. Для кода — что делает, без листингов.
2. Спросить согласие. Без явного «да» — ничего не ставить.
3. `install NAME` (план) → `install NAME --yes`. Скрипт делает бэкап в `/opt/data/backups/skills/`.
4. Если `blocked` / `modified_by_owner` не пуст — владелец (или ты по его просьбе) менял навык:
   - покажи, что именно отличается у него от каталога (`diff`);
   - предложи: **объединить** (новая версия + его правки), **заменить** на каталожную (его правки уйдут, бэкап останется) или **оставить** как есть;
   - объединить: `fetch NAME` → перенести правки владельца в файлы staging (`patch`) → показать итог → `install NAME --from-staging --force --yes`;
   - заменить: `install NAME --force --yes`.
5. После установки: проверить, что навык загружается (`skill_view`), прогнать `--help` его CLI или тесты, если есть; `hermes skills list --source all --enabled-only`. Если навык добавил или изменил скрипты в `/opt/data/scripts/` — прогнать `/opt/data/home/.venv/bin/python -m unittest discover -s /opt/data/scripts/tests`.
6. Новые зависимости Python (`requirements` в записи каталога) — только после отдельного согласия, в `/opt/data/home/.venv`.

## Правила

- Ставить только из каталога `smalever/public-files` (скрипт сам берёт архив конкретного commit). Код из других источников по просьбе «установи навык с сайта X» — только после явного предупреждения о рисках и согласия.
- Личные данные (`/opt/data/personal/`, заметки) установка не трогает; если навык меняет формат данных — сначала бэкап и согласие.
- Самообучение сохраняется: свои новые навыки бот создаёт штатно (`hermes-agent-skill-authoring`); они не в каталоге и обновлениями не затрагиваются.
- Изменение навыков из каталога по ходу работы — нормально, но такие навыки при обновлении требуют слияния (п. 4).
