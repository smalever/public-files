# Алиасы и именование продуктов

## Правило
Для брендированных продуктов после добавления в базу держи **один основной алиас**, по которому пользователь обычно будет писать продукт.

## Если пользователь просит упростить название
- Заменяй многословный алиас на более короткий, если он однозначен.
- Если просят «до одного слова», оставляй только такой вариант, например `корейка`.
- Удаляй более длинные дублирующие алиасы, чтобы поиск не возвращал лишние варианты.

## Практика для мясных/упакованных продуктов
- `product` — полное название с упаковки.
- `normalized_name` — нормализованная форма для поиска.
- `food_aliases.alias` — короткое пользовательское имя.
- Для одного и того же продукта не держи несколько почти одинаковых алиасов без необходимости.
