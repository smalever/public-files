# Алиасы и именование продуктов

## Правило
Для брендированных продуктов после добавления в базу держи **один основной алиас**, по которому пользователь обычно будет писать продукт.

## Если пользователь просит упростить название
- Заменяй многословный алиас на более короткий, если он однозначен.
- Если просят «до одного слова», оставляй только такой вариант, например `корейка`.
- Удаление старых алиасов или замена существующего соответствия — отдельная согласованная правка после явного подтверждения владельца; новый алиас не должен молча перезаписывать старый.

## Штатная команда

Используй `$PY $CLI alias-add --alias "название" --id ID --json` либо `--product "Точное название"` вместо `--id`. Прямой SQL к рабочей базе запрещён. Один продукт может иметь несколько разных полезных алиасов, независимо от категории продукта.

Повтор существующего соответствия идемпотентен; переназначение и коллизия с названием другого продукта отклоняются. Сопоставление учитывает регистр, е/ё и лишние пробелы. Успех проверяется read-only после commit внутри CLI, отдельный запрос не нужен.

## Практика для мясных/упакованных продуктов
- `product` — полное название с упаковки.
- `normalized_name` — нормализованная форма для поиска.
- `food_aliases.alias` — короткое пользовательское имя.
- Для одного и того же продукта не держи несколько почти одинаковых алиасов без необходимости.
