# Брендированные продукты с этикетки

Короткое правило для упаковок с готовыми салатами/закусками/гарнирами:

- Если на этикетке видно точное название, бренд и пищевую ценность на 100 г, записывать продукт по **этикетке**, а не заменять на среднее по интернету.
- Для базы использовать:
  - `product` = полное название с упаковки (включая бренд, если он важен для отличия продукта);
  - `normalized_name` = короткая нормализованная форма без лишнего шума;
  - `food_aliases.alias` = пользовательское краткое имя, по которому продукт будут писать дальше.
- Если пользователь пишет обобщённо (например, «морковь по-корейски»), а на упаковке есть точный бренд/вариант, сначала добавь точный продукт в `food_db`, потом `food_aliases` для короткого имени, и только затем повторяй запись приёма пищи.
- Для расчёта брать значения **на 100 г с этикетки**, а не средние интернет-оценки, если этикетка читается.

Пример из сессии:

- `Морковь по-корейски маринованная GREENOLA`
- Пищевая ценность на 100 г: `100 ккал`, `Б 4.0`, `Ж 4.0`, `У 11.0`
- Алиас: `морковь по-корейски`
