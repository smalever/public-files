# Консервы, фото этикетки и добавление нового продукта

## Когда применять
- Пользователь прислал фото банки/этикетки.
- Название блюда расплывчатое, но на упаковке видны БЖУ/ккал.
- В базе нет точного совпадения для готового консервированного блюда.

## Порядок действий
1. Считать с фото **название продукта** и **пищеую ценность на 100 г**.
2. Если на фото читаются БЖУ, использовать их как основной источник.
3. Если веб-источники дают разные значения, приоритет у значения на упаковке.
4. Если точного продукта нет в `food_db`, добавить новый продукт:
   - `product` — полное название с банки;
   - `normalized_name` — короткая нормализованная форма;
   - `food_aliases.alias` — пользовательская короткая формулировка.
5. После добавления повторно вызвать `meal` с точным названием из базы.

## Практический пример из сессии
- На фото банки были видны значения: **белки 6,0 г**, **жиры 16,0 г**, **углеводы 16,0 г**, **232 ккал на 100 г**.
- Был добавлен продукт:
  - `Каша гречневая с говядиной консервы`
  - `normalized_name = каша гречневая с говядиной консервы`
  - alias: `каша гречневая с говядиной`
- После этого обед записался без ошибки по точному названию.
