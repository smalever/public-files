# Probe Log (Deprecated)

Этот документ проб поисковых систем признан устаревшим (obsolete) и деактивирован.

Согласно политике навыка `web-search-fallbacks`, любые прямые обходные пути (прямые вызовы curl с браузерными User-Agent, скрипты, native web_search/web_extract, сторонние API и прямой скрейпинг сайтов) строго запрещены.

Поиск и чтение веб-источников производятся исключительно через приватный MCP-сервер SearXNG (`searxng_web_search` и `web_url_read`).
